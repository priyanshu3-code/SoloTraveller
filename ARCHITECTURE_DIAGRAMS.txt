DIAGRAM 3: Model Routing Decision Tree
════════════════════════════════════════════════════════════════════════════

LLM Task Requested
    ↓
    Is it safety-critical content screening?
    ├─ YES → Use Heavy Tier (70B - llama-3.3-70b-versatile)
    │        ├─ Content Moderation ✓
    │        └─ Judge Validation ✓
    │
    └─ NO → Is it final confidence validation?
            ├─ YES → Use Heavy Tier (70B)
            │
            └─ NO → Use Fast Tier (8B - llama-3.1-8b-instant)
                    ├─ Main Risk Analysis ✓
                    ├─ Advice Generation ✓
                    ├─ Summary Creation ✓
                    └─ Evaluation Logic ✓

RESULT:
  Heavy Tier (70B): 2 out of 5 LLM calls    = 40% of work
  Fast Tier (8B):   3 out of 5 LLM calls    = 60% of work

  Cost = (0.40 × 70B_cost) + (0.60 × 8B_cost)
       = (0.40 × 0.59) + (0.60 × 0.05)
       = 0.236 + 0.03
       = 0.266 per million tokens (vs 0.40 if all 70B)

  SAVINGS: (0.40 - 0.266) / 0.40 = 33.5% cost reduction

DIAGRAM 5: Error Handling Flow
═════════════════════════════════════════════════════════════════════════════

BEFORE (❌ Cascading Failures):
──────────────────────────────

LLM Call
    ↓
Error Occurs (429)
    ↓
No Retry Logic
    ↓
Exception Raised
    ↓
Downstream Calls Skip (not sent)
    ↓
LangSmith Traces Incomplete
    ↓
Response: null or 500 error
    ↓
User sees: "Something went wrong"


AFTER (✅ Graceful Degradation):
────────────────────────────────

LLM Call
    ↓
Error Occurs (429)
    ↓
Caught by Backoff Wrapper
    ↓
Check: Is it a rate limit error?
    ├─ YES → Retry with exponential backoff
    │        ├─ Wait and retry
    │        ├─ (Success?) → Return response
    │        └─ (Still failing?) → Continue retry loop
    │
    └─ NO → Log error immediately
            └─ Raise exception

After Max Retries:
    ↓
Still Failing?
    ├─ YES → Use Graceful Fallback
    │        └─ Generate_fallback_response()
    │           ├─ Structured JSON with defaults
    │           ├─ All downstream spans still processed
    │           └─ User gets: valid response with warnings
    │
    └─ NO → Return LLM response normally

LangSmith Traces: All captured
Response: Always valid JSON
User Experience: No crashes!
